# Phase 1 Degeneration Corpus

This directory contains the Phase 1 degeneration corpus for the Network_Credible_Intervals project: a deterministically-reproducible set of dropped-node records generated by running the centrality-correlated missingness sampler over the validation network corpus.

The corpus is the input to the framework-evaluation phase (Phase 2). Each row records one realization of degenerated-network sampling for a given (network, induced correlation, missingness rate, replicate, mechanism) cell. The corpus stores dropped-node *sets*, not degraded networks themselves — degraded networks are reconstructed on demand by calling `apply_missingness` or `apply_missingness_outgoing_only` against the original network and the recorded dropped-node vector.

## Files

| File | Description |
|---|---|
| `degeneration_corpus.arrow` | 78,000-row Arrow file (zstd-compressed, ~17 MB) containing the full corpus. |

## File format

Arrow with zstd compression. Reads cleanly from both Julia (`Arrow.Table`) and R (`arrow::read_feather`). The `dropped_nodes` column is stored natively as a vector-of-vectors; no string parsing required.

## Generation

Produced by `generate_corpus.jl` (in the project's `julia_env/` tree) on 2026-05-29 using:

- Master seed: `42`
- Julia version: `1.11.2`
- 8 threads, single workstation, ~10 minutes wall-clock
- Source corpus: 18 GraphML files in `Data/GraphML_Test_Networks/`

To regenerate from scratch:

```julia
# From the project root, with Threads.nthreads() >= 4:
include("julia_env/generate_corpus.jl")
```

The generation is deterministic in `master_seed`: identical seed produces bit-identical output (verified via Test 4 in the validation harness and via the post-run spot check).

## Schema

17 columns, one row per (network, ρ, rate, replicate, mechanism) tuple.

### Identifiers and provenance

| Column | Type | Description |
|---|---|---|
| `network_name` | String | One of the 18 corpus networks (see below). |
| `nominal_rho` | Float64 | Target centrality–missingness correlation: one of {-0.75, -0.25, 0.0, 0.25, 0.75}. |
| `nominal_rate` | Float64 | Target removal fraction: one of {0.05, 0.10, 0.15, 0.25, 0.40, 0.50}. |
| `replicate_idx` | Int | 1..100 within each (network, ρ, rate) cell. |
| `mechanism` | Symbol | `:full_removal` or `:outgoing_only` (see Mechanisms below). |
| `seed` | Int | Per-cell deterministic sub-seed derived from `master_seed`. Used by `generate_missingness_mask` to reproduce this row in isolation. |

### Sampler output

| Column | Type | Description |
|---|---|---|
| `dropped_nodes` | `Vector{Int}` | Indices (in canonical node order) of nodes selected for removal. |
| `realized_rate` | Float64 | `length(dropped_nodes) / N` for the network. |
| `realized_rho` | Float64 | Realized `cor(is_dropped, centrality)` for this draw. Signed against the original centrality direction. |
| `bisection_status` | Symbol | `:converged` (target ρ achieved), `:ceiling_hit` (target unreachable on this network — see Ceiling caveat below), or `:failed_other` (rare; structural failure like constant centrality). |

### Sampler-level topological degeneracy

These fields describe the structural state of the network when the dropped-node mask is applied to the original adjacency. They are **mechanism-agnostic** by design: both mechanism rows for the same (network, ρ, rate, replicate) cell share these values.

| Column | Type | Description |
|---|---|---|
| `gc_fraction_of_remaining` | Float64 | Largest connected component as a fraction of *surviving* nodes (not original). |
| `n_observed` | Int | Number of surviving nodes. |
| `n_edges_observed` | Int | Number of surviving edges *under the full-removal mechanism* (the SMM-style outgoing-only mechanism preserves more edges, but the degeneracy field reflects the canonical full-removal reading). |
| `gc_collapse` | Bool | True when `gc_fraction_of_remaining < 0.30`. |
| `too_small` | Bool | True when `n_observed < 25`. |
| `no_edges` | Bool | True when `n_edges_observed < 1`. |
| `any_topo_degenerate` | Bool | Disjunction of the three flags above. |

## Mechanisms

Each (network, ρ, rate, replicate) cell produces one row per applicable materialization mechanism:

- **`:full_removal`** — The dropped nodes are removed entirely from the network along with all their edges. Corresponds to the design document's Stage 1 scenario (fully unobserved non-respondents reconstructed from scratch).
- **`:outgoing_only`** — Directed networks only. The dropped nodes remain in the node roster but have their outgoing edges removed; their incoming edges (from observed respondents) are preserved. Corresponds to the design document's Stage 0.5 scenario (nominated non-respondents whose existence is known via incoming nominations but whose outgoing behavior must be imputed). Silently skipped on undirected networks.

Both mechanisms consume the **same** dropped-node set per cell — only the materialization differs. This selection invariance means the sampler runs once per cell; both materializers reuse the dropped-node vector. The corpus reflects this: for directed networks, consecutive output rows for the same cell share `seed`, `dropped_nodes`, `realized_rate`, `realized_rho`, `bisection_status`, and all degeneracy fields, differing only in `mechanism`.

## Ceiling-hit caveat (critical for downstream consumers)

Approximately 64% of the corpus is flagged `:ceiling_hit` — meaning the bisection determined the target ρ was unreachable on that network at that rate. **Downstream analysis must use `realized_rho`, not `nominal_rho`**, for any computation that conditions on the missingness correlation.

The ceiling rate is high because the corpus deliberately includes networks where extreme ρ targets (±0.75) are structurally unreachable. Two patterns explain most of it:

1. **Asymmetric ceilings on heavy-tailed networks** (Marvel, Balikatan, both PA variants, Toledo, Scotland): the positive direction reaches realized ρ around 0.4–0.5 at the ceiling; the negative direction reaches only around -0.03 to -0.10 because the low-centrality mass is structurally indistinguishable. See the Asymmetric ceilings paragraph in `validation_roadmap.tex` (Section 4) for the methodological discussion.

2. **Low-centralization networks** (Synthetic 1 SBM directed/undirected): both directions hit ceilings well below ±0.25 because the SBM was designed with low centralization to anchor that endpoint of the corpus.

The `bisection_status` column distinguishes the three cases explicitly. The `:converged` rows (28,000+ of them) are where the target ρ was achieved within tolerance 0.02. The `:ceiling_hit` rows are where the target was unreachable; `realized_rho` records what was actually achieved. The `:failed_other` rows (1 in the entire corpus, on Scotland weighted) are rare structural failures and should be excluded from analysis.

## Loading the corpus

### Julia

```julia
using Arrow, DataFrames

corpus = DataFrame(Arrow.Table("degeneration_corpus.arrow"))

# Subset to converged rows only:
clean = filter(:bisection_status => ==(:converged), corpus)

# Subset to a specific cell:
cell = filter(r -> r.network_name == "moreno_highschool_weighted" &&
                     r.nominal_rho  == 0.25 &&
                     r.nominal_rate == 0.10 &&
                     r.mechanism    == :full_removal,
              corpus)
```

### R

```r
library(arrow)
corpus <- arrow::read_feather("degeneration_corpus.arrow")

# Note: the dropped_nodes column comes through as a list-column of integer
# vectors. The bisection_status and mechanism columns come through as
# character; convert to factor if downstream code expects ordered levels.
```

## Reconstructing a degraded network

The corpus stores dropped-node sets, not degraded networks. To materialize a specific cell's degraded network:

```julia
using Network_Credible_Intervals
import Network_Credible_Intervals.network_degeneracy: apply_missingness,
                                                       apply_missingness_outgoing_only,
                                                       load_graphml

# Load the original network
net = load_graphml("path/to/network_name.graphml")

# Get a row from the corpus
row = corpus[idx, :]
dropped = collect(row.dropped_nodes)

# Materialize under the recorded mechanism
if row.mechanism == :full_removal
    degraded = apply_missingness(net.edges, dropped; nodes = net.nodes)
else  # :outgoing_only — directed networks only
    degraded = apply_missingness_outgoing_only(
        net.edges, dropped; nodes = net.nodes, directed = true
    )
end

# degraded.edges and degraded.nodes are the degraded network's components
```
